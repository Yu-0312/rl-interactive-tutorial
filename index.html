Suggested learning path

If you are new to RL, follow this order before jumping to deep methods.

  1. Formalize the MDP: states, actions, transitions, rewards, discount γ.
  2. Solve small MDPs exactly with Policy / Value Iteration (Week 2).
  3. Learn without a model using TD methods: SARSA and Q-learning (Week 3).
  4. Scale up with function approximation and neural networks (Weeks 4–5).
  5. Optimize policies directly for continuous control and stability (Weeks 6–7, 10).
  6. Extend the setting: human preferences, multi-agent, model-based (Weeks 11–13).
  7. Ship research-quality experiments with rigorous evaluation (Week 14).

How to use this tutorial

Run every demo

Change hyperparameters (α, ε, γ), step algorithms, and watch value functions / policies update. Intuition beats memorization.

Pair with a library

After tabular demos, implement the same algorithm with NumPy or PyTorch. Gymnasium’s CliffWalking-v0 and CartPole-v1 are good first targets.

Write weekly notes

For each algorithm: objective, update rule, on-policy vs off-policy, failure modes. This becomes your term-project literature review.

Project checkpoints

Weeks 8–9: proposal. Weeks 15–16: presentation. Weeks 17–18: report writing. Use the experiment-design checklist in Week 14.
