新手建議怎麼學

不要跳過第 1–3 週。後面的花式方法，都是建立在這三週的直覺上。

  1. 第 1 週：先弄懂「RL 就是試誤學習」。不需要先會 ML。
  2. 第 2 週：手算 Return / Value / γ，再玩 GridWorld 看價值往回流。
  3. 第 3 週：Q 表從 0 開始更新；比較 SARSA 與 Q-learning；跑 Python。
  4. 第 4–5 週：狀態太多時，改用函數 / 神經網路「估」價值（這時才要 ML）。
  5. 第 6–7、10 週：另一條路——直接學「看到什麼就做什麼動作」（策略方法）。
  6. 第 11–13 週：開眼界，知道 RL 還能做什麼。
  7. 第 14 週：如果要做專題，學會「怎麼把實驗做好」。
讀法建議。 每課依序：① 點選「先想一想 / 小挑戰」按鈕作答 → ② 看回饋與完整說明 → ③ 讀程式 → ④ 玩演示 → ⑤ 有餘力再看「更深一點」。 公式出現時，你應該已經先懂它在講的故事。
