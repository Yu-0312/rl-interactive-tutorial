Policy Search II: Policy Gradient (REINFORCE & PPO)

Optimize a parameterized stochastic policy πθ(a|s) directly by ascending the expected return — works with continuous actions and is the backbone of modern LLM RLHF.

Policy gradient theorem

∇θ J(θ) = 𝔼πθ [ ∇θ log πθ(A|S) · ψ ]

where ψ is a return / Q / advantage estimate. Score-function gradient: no need to differentiate through P.

REINFORCE

∇J ≈ Σt ∇ log π(At|St) · Gt

Monte-Carlo, unbiased, high variance. Fixes:

  • Baseline b(s): use $G_t - b(s)$ (doesn’t bias the gradient).
  • Discounted returns / reward scaling.
  • Actor-critic: learn $b \approx V(s)$ (Week 10).

Advantage & GAE

Aλt = Σl=0∞ (γλ)l δt+l,   δt = rt + γV(st+1) − V(st)

GAE (λ) trades bias vs variance. PPO implementations almost always use it.

PPO-Clip

Trust-region style updates without a KL constraint on the optimizer:

rt(θ) = πθ(a|s) / πθ_old(a|s)
L = 𝔼[ min( r·A , clip(r, 1−ε, 1+ε)·A ) ]

If the new policy moves too far from the data-collection policy, the objective flattens — preventing destructive steps while allowing multiple epochs per batch.

PPO engineering tips

  • Normalize advantages per batch.
  • Entropy bonus early in training; anneal it.
  • Value loss coefficient ~0.5; clip value loss separately.
  • Mini-batch epochs 3–10; watch approximate KL.
  • Vectorized envs (16–64) for stable batch stats.
RLHF connection. PPO with a KL penalty to a reference policy is the classic fine-tuning recipe for language models from human/AI preference scores.
