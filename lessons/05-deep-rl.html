深度強化學習：DQN 與 Rainbow

用深度網路 $Q(s,a;\theta)$ 取代線性 FA，並用兩大技巧穩定學習： 經驗回放（replay）與目標網路（target network）。

為何樸素深度 Q 會失敗

  • 連續樣本高度相關，破壞 SGD 假設。
  • bootstrap 目標隨 θ 移動 → 震盪 / 發散（致命三合組）。

DQN 更新

y = R + γ maxa' Q(S', a'; θ⁻)   （θ⁻ = 凍結的目標權重）
Loss = ( Q(S,A; θ) − y )²

把轉移 $(s,a,r,s',done)$ 存進 replay buffer；採樣 minibatch；定期 複製 $\theta \leftarrow \theta^-$。

Double DQN 減少高估：用 $a^* = \arg\max_{a'} Q(s',a';\theta)$ 選動作， 但用 $Q(s', a^*; \theta^-)$ 評估。

Rainbow：組合式改進

元件想法角色
DQNReplay + 目標網路深度 Q 基線
Double Q解耦選動作/評估減少高估
優先 replay高 |TD| 更常被採樣樣本效率
Dueling拆開 V(s) 與 A(s,a)更好的價值學習
多步n-step 回報更快信用分配
Noisy nets可學習權重雜訊狀態相關探索
C51 分佈式建模 Z(s,a)，不只 E[Z]更豐富目標、更穩

Rainbow（Hessel et al., 2018）顯示組合後在 Atari 上優於各單項。
