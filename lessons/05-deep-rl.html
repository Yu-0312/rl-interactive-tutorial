用神經網路學 Q 值：DQN

一句話總結。 把估 Q 的公式換成神經網路，就是 DQN。 為了不讓網路學崩，加了經驗回放與目標網路。 訓練本質仍是：loss + 梯度下降。

你需要會的三件事

① loss 在量什麼；② 梯度下降是「參數往 loss 小的方向走」；③ 網路 = 可調的多層函數。

就這些

為什麼「直接把表格換成網路」會炸？

  • 資料太黏：連續幾步幾乎長一樣，網路容易只記得最近這一小段。
  • 目標一直在動：你用網路自己算「下一格價值」，而權重每步都在改——像追一個一直跑走的靶子。
先想一想 · 點選答案

若老師改考卷的「標準答案」每秒都在變（來自學生自己的草稿），會怎樣？

完整說明

這就是「用自己當目標」的危險。配合經驗回放：別只用最近的黏答答資料。

y = r + γ max Q(s′,a′; θ⁻)　← 用較舊的 θ⁻ 算目標

兩大穩定技巧

1. 經驗回放 Replay

把 (s,a,r,s′) 丟進大袋子，訓練時隨機抽一把舊經驗，而不是只用剛剛發生的。

白話：別只背今天的事，偶爾翻舊筆記。

2. 目標網路 Target

另存一份較舊的權重 θ⁻，過一陣子才更新；訓練目標用它算。

白話：改考卷用上週答案，不是每秒都在改的草稿。

DQN 流程（白話版）

  1. 狀態 s → Q 網路看哪個動作分數高 → 做動作（有時亂試）。
  2. 拿到 r、s′，經驗丟進回放袋。
  3. 隨機抽一批舊經驗。
  4. 用目標網路算目標 y = r + γ max Q(s′,a′; θ⁻)。
  5. loss = (Q(s,a;θ) − y)²，更新 θ。
  6. 每隔幾步把 θ 複製到 θ⁻。
y = r + γ maxa′ Q(s′, a′; θ⁻)
Loss = ( Q(S,A; θ) − y )²
Double DQN（聽過就好）。 用目前網路挑「哪個動作最好」，用目標網路打那個動作的分數。 挑和評分分開 → 高估少一點。

概念版 PyTorch 實作

這是「心智模型可跑版」，不是完整 Atari 引擎。讀懂它，論文 code 就不會全是天書。

import random
import torch
import torch.nn as nn
import torch.nn.functional as F

class QNet(nn.Module):
    def __init__(self, n_obs, n_actions):
        super().__init__()
        self.fc = nn.Sequential(
            nn.Linear(n_obs, 64), nn.ReLU(),
            nn.Linear(64, n_actions),
        )
    def forward(self, x):
        return self.fc(x)

n_obs, n_actions = 4, 2
q = QNet(n_obs, n_actions)
q_target = QNet(n_obs, n_actions)
q_target.load_state_dict(q.state_dict())
opt = torch.optim.Adam(q.parameters(), lr=1e-3)

replay = []  # [(s, a, r, s2, done), ...]
gamma = 0.99
batch_size = 32

def act(state, epsilon=0.1):
    if random.random() < epsilon:
        return random.randrange(n_actions)
    with torch.no_grad():
        qs = q(torch.tensor(state, dtype=torch.float32))
        return int(qs.argmax())

def train_step():
    if len(replay) < batch_size:
        return
    batch = random.sample(replay, batch_size)
    s, a, r, s2, d = zip(*batch)
    s = torch.tensor(s, dtype=torch.float32)
    a = torch.tensor(a, dtype=torch.int64)
    r = torch.tensor(r, dtype=torch.float32)
    s2 = torch.tensor(s2, dtype=torch.float32)
    d = torch.tensor(d, dtype=torch.float32)

    q_sa = q(s).gather(1, a.view(-1, 1)).squeeze(1)
    with torch.no_grad():
        # 目標網路算 y（穩定的靶）
        y = r + gamma * q_target(s2).max(1).values * (1 - d)

    loss = F.mse_loss(q_sa, y)
    opt.zero_grad()
    loss.backward()
    opt.step()

動手玩：目標網路有沒有用？

你可以這樣玩：

  1. 目標延遲選「無」→ 曲線通常較抖。
  2. 改「每 10 步」→ 通常更平穩。
  3. 「每 50 步」→ 目標很舊，可能變慢但不亂飛。
