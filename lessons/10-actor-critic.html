演員 + 評論家：Actor-Critic

一句話總結。 Actor 決定做什麼動作； Critic 打分「這狀態 / 動作大概值多少」。 兩個一起練。連續控制主流是 DDPG、TD3、SAC。

為什麼要兩個網路？

Actor：看到狀態 → 直接輸出動作
Critic：看到狀態+動作 → 輸出 Q 分數

Critic 用 TD 學打分（像第 5 週）
Actor 調整自己，讓 Critic 對「我輸出的動作」打更高分
生活比喻

演員在台上即興；評論家在台下打分。兩邊如何一起進步？

看展開

演員看「上次這樣演分數高」就繼續；評論家看多了戲，分數愈打愈準。

若只有 REINFORCE：要整局結束才知道好壞，訊號很吵。Critic 提供每步的「現在幾分」。

DDPG：連續動作版 DQN 思路

  • Actor + Critic 都有回放袋與目標網路。
  • 探索：在 Actor 輸出上加雜訊。
  • Actor 目標：輸出的動作讓 Critic 的 Q 盡量高。
∇θJ ≈ 𝔼[ ∇θμ(s) · ∇a Q(s,a)|a=μ(s) ]

TD3：修 DDPG 的三個毛病

  1. 雙評論家（Twin）：兩個 Critic，目標取 min。
    白話：兩個評審，先當比較嚴的那位說了算——不易自我感覺良好。
  2. 延遲更新 Actor（Delayed）：評論家多練幾次，演員少改幾次。
  3. 目標策略平滑：算目標時對動作加一點雜訊，別對單點過度自信。
y = r + γ · min(Q₁, Q₂)( s′, π(s′)+ε )

SAC：動作也要保持多樣

目標 ≈ 獎勵 + α × 熵（策略的隨機程度）

白話：不只看戰績，也鼓勵「別把所有局打成同一套」。常更穩、樣本效率不錯。

REDQ：很多個 Critic，每次隨機抽幾個取 min——更嚴格、更省樣本。

概念版：雙 Q 取 min

import torch
import torch.nn as nn
import torch.nn.functional as F

class Critic(nn.Module):
    def __init__(self, n_obs, n_act):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_obs + n_act, 64), nn.ReLU(),
            nn.Linear(64, 1),
        )
    def forward(self, s, a):
        return self.net(torch.cat([s, a], dim=-1)).squeeze(-1)

class Actor(nn.Module):
    def __init__(self, n_obs, n_act):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_obs, 64), nn.ReLU(),
            nn.Linear(64, n_act), nn.Tanh(),  # 動作假設在 [-1,1]
        )
    def forward(self, s):
        return self.net(s)

q1, q2 = Critic(4, 2), Critic(4, 2)
actor = Actor(4, 2)
opt_q = torch.optim.Adam(list(q1.parameters()) + list(q2.parameters()), lr=1e-3)
opt_a = torch.optim.Adam(actor.parameters(), lr=1e-3)
gamma = 0.99

def td3_targets(r, s2, done):
    with torch.no_grad():
        a2 = actor(s2)
        # 目標策略平滑：加一點裁剪雜訊
        a2 = (a2 + 0.1 * torch.randn_like(a2)).clamp(-1, 1)
        q1_next = q1(s2, a2)
        q2_next = q2(s2, a2)
        y = r + gamma * torch.min(q1_next, q2_next) * (1 - done)
    return y

# 更新 Critic：兩個 Q 都逼近 y
# 更新 Actor（可延遲幾步再更）：最大化 q1(s, actor(s))
# 重點是 min(Q1,Q2) —— 對抗高估

動手玩：為什麼雙評論家重要

你可以這樣玩：

  1. 勾選「使用 min(Q1,Q2)」，多按「重新採樣評論家」，看選中動作穩不穩。
  2. 取消勾選再採樣：可能被某個虛高評論家帶跑。
  3. 雜訊調高：min 的保護效果更明顯；對照「相對最優後悔」。
