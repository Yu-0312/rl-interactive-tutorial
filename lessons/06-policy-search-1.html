策略搜尋 I：不靠梯度也能搜

一句話總結。 有時算不出「往哪調參數會更好」。 那就多試幾組參數、看誰分數高、往好的那邊靠——像養一群候選人，淘汰爛的。 這叫無梯度優化。

黑盒搜尋：只看分數

在目前參數附近隨機微調 → 每個版本玩幾局記分
→ 分數高的改法加總起來 → 作為這次要走的方向
→ 重複
∇J ≈ (1/nσ) Σᵢ J(θ+σεᵢ) · εᵢ　（εᵢ 是隨機雜訊向量）
先想一想

這和 ML 補課 2 的梯度下降有什麼相同與不同？

看答案

相同：都要更新參數，都希望「某個分數 / loss 變好」。

不同： 梯度下降需要對 loss 微分（要模型可微）； 無梯度方法只用「試出來的回報」估方向，不需要對環境反向傳播。

最小 ES：看得懂就夠了

import random

# 假參數：一個數字。目標函數黑盒（我們不對它微分）
theta = 0.0
sigma = 0.1      # 探索半徑
lr = 0.3
n_samples = 20

def J(th):
    # 真實世界可能是：跑一局遊戲的總分
    # 這裡用一個有峰的函數代替，峰值在 th=2
    return -((th - 2.0) ** 2) + 1.0

for step in range(40):
    # 1) 在 theta 周圍採樣很多微調
    noises = [random.gauss(0, 1) for _ in range(n_samples)]
    rewards = [J(theta + sigma * e) for e in noises]

    # 2) 把「分數高的改法」加起來（這裡用簡單加權平均）
    mean_r = sum(rewards) / n_samples
    grad_est = sum((r - mean_r) * e for r, e in zip(rewards, noises))
    grad_est /= n_samples * sigma

    # 3) 往估計方向走一小步
    theta += lr * grad_est
    if step % 10 == 0:
        print(f"step={step:02d}  theta={theta:.3f}  J={J(theta):.3f}")

print("theta 應接近 2")

ERL 與 CEM-RL（名詞版）

  • ERL（演化+RL）：演化負責大範圍探索；梯度 RL 負責局部精修。
  • CEM：抽樣 → 只留精英 → 用精英重擬合分佈 → 再抽。
  • CEM-RL：一半族群演化篩選，一半用 Actor-Critic 梯度更新。
白話：演化像「海選 + 留種」，梯度像「入選後精雕」。 兩者混用，比單打獨鬥穩。

和策略梯度比一比

無梯度（ES / CEM）策略梯度（下一週）
策略要可微嗎不用要
樣本效率通常較差通常較好
平行友好非常適合也適合
容易全卡在爛解較不易（一群）單一策略要小心初始化

什麼時候考慮無梯度

  • 環境黑盒、不可微、充滿硬切換。
  • 有很多平行機器。
  • 想先探索出幾條路線，之後再蒸餾成單一策略。
更深一點 · 為何實驗室仍以梯度為主

參數上百萬時，純演化通常要跑更多回合。 但在不可微模擬、稀疏獎勵、或模擬器很吵時，演化反而穩健。 工程上也有「ES 找種子 → PPO 精修」的混合配方。
