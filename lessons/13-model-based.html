先學世界規則，再在想像中訓練

一句話總結。 真實互動很貴。模型式 RL：先從經驗學一個「世界預測器」， 再在腦內模擬訓練或規劃，省下大量真實互動。

生活比喻

國手不只靠實戰——也打譜、在腦中推演
模型式 RL = 先學棋理（世界模型），再在腦中練
  • 無模型 PPO/SAC 可能要上百萬步環境互動。
  • 真實機器人：每一步耗時、耗錢、有風險。
先想一想 · 點選答案

在想像中練太多，最大的風險是什麼？

完整說明

緩解：短視界、動力學集成、不確定處提早砍軌跡、真實與想像混著練。

路線一：短想像 + 策略優化（ME-TRPO 思路）

  1. 用真實經驗訓練好幾個動力學模型（集成）。
  2. 目前策略在模型裡假裝玩幾步，產生短軌跡。
  3. 用這些想像資料做 PPO/TRPO 更新。
  4. 回真實環境收新資料，再更新模型。
為什麼要集成？ 多個模型意見不合 → 此處不確定 → 別在想像中走太遠。

路線二：Dreamer——在潛在狀態裡完整練

  1. 世界模型：把觀察壓成內部狀態，學「做這動作後會怎樣 + 大概多少獎勵」。
  2. 想像中練習：Actor-Critic 完全在內部狀態序列裡訓練。
  3. 真實互動：只用來收資料、修世界模型。

世界模型的 I/O 長什麼樣

import torch
import torch.nn as nn

class WorldModel(nn.Module):
    """極簡：預測下一狀態與獎勵（不是 RSSM，只抓 I/O 形狀）"""
    def __init__(self, n_obs, n_act):
        super().__init__()
        self.next = nn.Sequential(
            nn.Linear(n_obs + n_act, 64), nn.ReLU(),
            nn.Linear(64, n_obs),
        )
        self.reward = nn.Sequential(
            nn.Linear(n_obs + n_act, 64), nn.ReLU(),
            nn.Linear(64, 1),
        )
    def forward(self, s, a):
        x = torch.cat([s, a], dim=-1)
        return self.next(x), self.reward(x).squeeze(-1)

model = WorldModel(4, 2)

# 想像 rollout（示意）
def imagine(s, actor, horizon=5):
    traj = []
    for _ in range(horizon):
        a = actor(s)                 # 假設 actor 存在
        s_hat, r_hat = model(s, a)
        traj.append((s_hat, r_hat))
        s = s_hat
        # 真實方法會在集成不確定處提早砍掉
    return traj

print("真實互動用來訓練 model；策略更新可用想像資料")
