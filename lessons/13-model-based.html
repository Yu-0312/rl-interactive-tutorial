Sample Efficiency: Model-based RL

Learn a dynamics model $\hat{P}$ (and reward) from experience, then plan or generate imagined rollouts — cutting real environment interactions by orders of magnitude.

Motivation

  • Model-free PPO/SAC may need 10⁶–10⁷ steps.
  • Robots, expensive sims, or limited real-world data favor models.
  • Planning (MPC) gives interpretability and constraint handling.

ME-TRPO

Model-Ensemble TRPO (Kurutach et al.): train an ensemble of dynamics networks, sample short imagined trajectories, and take a TRPO/PPO step on the model-predicted objective. Ensembles capture epistemic uncertainty → shorter rollouts where models disagree.

maximize 𝔼[ Σ γt r̂(ŝ,â) ]   s.t.   KL(πold ‖ π) ≤ δ

Dreamer / DreamerV3

  1. World model (RSSM): latent state + recurrent dynamics + decoder + reward head.
  2. Imagination: actor-critic trained entirely in latent rollouts.
  3. Act in the real env to collect more data; repeat.

DreamerV3 uses symlog predictions, return normalization, and robust defaults to train from pixels across many domains with a single hyperparameter set.

The model-error problem

Compounding error. Multi-step predictions drift; policies exploit model bugs (causal confusion, adversarial states). Mitigations: short horizons, ensembles, uncertainty penalties, data aggregation (Dyna / MBPO style short model rollouts).

Practical recipe for a project

  1. Start with a strong model-free baseline (SAC/PPO).
  2. Add a short-horizon ensemble model; only inject k-step synthetic data.
  3. Ablate real vs imagined batch ratio; plot sample-efficiency curves.
  4. Measure model open-loop prediction error on held-out trajectories.
