樣本效率：基於模型的 RL

從經驗學動力學模型 $\hat{P}$（與獎勵），再規劃或產生 想像中的 rollout——把真實環境互動量降一個數量級。

動機

  • 無模型 PPO/SAC 可能需要 10⁶–10⁷ 步。
  • 機器人、昂貴模擬或有限真實資料偏好模型。
  • 規劃（MPC）可解釋、好加約束。

ME-TRPO

Model-Ensemble TRPO（Kurutach et al.）：訓練動力學網路集成， 採樣短想像軌跡，在模型預測目標上做 TRPO/PPO 步。 集成捕捉認知不確定性 → 在模型分歧處縮短 rollout。

maximize 𝔼[ Σ γt r̂(ŝ,â) ]   s.t.   KL(πold ‖ π) ≤ δ

Dreamer / DreamerV3

  1. 世界模型（RSSM）：潛在狀態 + 遞歸動力學 + 解碼器 + 獎勵頭。
  2. 想像：Actor-Critic 完全在潛在 rollout 中訓練。
  3. 行動：在真實環境收集更多資料；重複。

DreamerV3 使用 symlog 預測、回報正規化與穩健預設， 以單一超參數集合從像素跨多領域訓練。

模型誤差問題

誤差複合。 多步預測會漂移；策略會利用模型漏洞 （因果混淆、對抗狀態）。緩解：短視界、集成、不確定性懲罰、 資料聚合（Dyna / MBPO 風格短模型 rollout）。
方法模型用於風險
規劃 / MPC每步選動作視界太短則短視
MBPO 式 Dyna額外合成轉移合成資料偏差
Dreamer在潛在想像中完整學策略世界模型誤設

專題實作配方

  1. 先做強無模型基線（SAC/PPO）。
  2. 加短視界集成模型；只注入 k 步合成資料。
  3. 消融真實 vs 想像批次比例；畫樣本效率曲線。
  4. 在保留軌跡上量測模型開環預測誤差。
