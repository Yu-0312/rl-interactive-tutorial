無模型演算法：SARSA 與 Q-learning

拋開轉移模型。用時序差分（TD） backup，直接從採樣經驗學習動作價值 $Q(s,a)$。

從 DP 到採樣

DP 對所有 $s'$ 求和；無模型方法用單筆樣本替換該期望：

Σs' P(s'|s,a) f(s') ≈ f(S') ，其中 S' ~ P(·|s,a)

取捨：需要更多資料，但 $P$ 未知或巨大時仍可用。

TD 目標與 TD 誤差

δ = R + γ V(S') − V(S)   （Q 版：R + γ Q(S',A') − Q(S,A)）

把估計往目標方向移動一小步 α（學習率）。

SARSA（同政策 / on-policy）

State, Action, Reward, S', A'——使用策略實際會做的下一動作。

Q(S,A) ← Q(S,A) + α [ R + γ Q(S',A') − Q(S,A) ]

因為 bootstrap 使用 $A' \sim \pi(\cdot|S')$，SARSA 學到的是 行為策略的價值（包含探索雜訊）。

Q-learning（離政策 / off-policy）

Q(S,A) ← Q(S,A) + α [ R + γ maxa' Q(S',a') − Q(S,A) ]

用貪婪 max bootstrap，同時仍以 ε-greedy 探索。 在標準條件下學習 $Q^*$，與探索策略無關。

經典懸崖結果。 在「懸崖」網格上，Q-learning 的最優路徑貼著懸崖邊（最優但探索時危險）。 SARSA 學到更安全的內陸路徑，因為學習過程中探索會掉下懸崖。

探索策略

  • ε-greedy：以機率 ε 隨機動作；否則貪婪。簡單有效。
  • Softmax / Boltzmann：依 exp(Q/τ) 採樣。溫度 τ 控制探索。
  • 樂觀初始化：較高的初始 Q 鼓勵造訪未知動作。
  • UCB / 計數式：不確定性加成——後續樣本效率週。
收斂備註。 表格型 Q-learning 在 GLIE 探索與 Robbins–Monro 步長 （$\sum \alpha=\infty$，$\sum \alpha^2 < \infty$）下收斂到 $Q^*$。 實務上常用常數 α 與有限 ε——能用，但沒有形式保證。
