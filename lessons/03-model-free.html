Model-Free Algorithms: SARSA & Q-learning

Drop the transition model. Learn action values $Q(s,a)$ directly from sampled experience using temporal-difference (TD) backups.

From DP to sampling

DP sums over all $s'$. Model-free methods replace that expectation with a single sample:

Σs' P(s'|s,a) f(s') ≈ f(S') where S' ~ P(·|s,a)

Trade-off: more data needed, but works when $P$ is unknown or huge.

TD target & TD error

δ = R + γ V(S') − V(S)    (or with Q: R + γ Q(S',A') − Q(S,A))

You move the estimate toward the target by a step size α (learning rate).

SARSA (on-policy)

State, Action, Reward, S', A' — uses the next action the policy actually takes.

Q(S,A) ← Q(S,A) + α [ R + γ Q(S',A') − Q(S,A) ]

Because the bootstrap uses $A' \sim \pi(\cdot|S')$, SARSA learns the value of the behavior policy (including its exploration noise).

Q-learning (off-policy)

Q(S,A) ← Q(S,A) + α [ R + γ maxa' Q(S',a') − Q(S,A) ]

Bootstraps with the greedy max while still exploring with ε-greedy behavior. Learns $Q^*$ regardless of the exploratory policy (under standard conditions).

Classic cliff result. On the “Cliff” grid, Q-learning’s optimal path walks the cliff edge (optimal but risky under exploration). SARSA learns a safer inland path because exploration falls off the cliff during learning.

Exploration strategies

  • ε-greedy: random action w.p. ε; greedy otherwise. Simple, effective.
  • Softmax / Boltzmann: sample ∝ exp(Q/τ). Temperature τ controls exploration.
  • Optimistic init: high initial Q encourages visiting unknown actions.
  • UCB / count-based: bonus for uncertainty — later sample-efficiency weeks.
Convergence note. Tabular Q-learning converges to $Q^*$ with GLIE exploration and Robbins–Monro step sizes ($\sum \alpha=\infty$, $\sum \alpha^2 < \infty$). In practice we use constant α and finite ε — works, but no formal guarantee.
