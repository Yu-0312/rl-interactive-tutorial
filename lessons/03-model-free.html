沒有說明書時：Q 表怎麼從零學會

一句話總結。 不知道環境規則也沒關係：Agent 靠經驗表（Q 表）記住 「在這裡做這個動作，之後大概值多少」， 每走一步就用「剛剛看到的結果」修正一點。 Q-learning 用「下一格最好的值」來修正；SARSA 用「實際會走的下一步」。

先建立一個關鍵直覺：從經驗中學

探索 → 得到經驗 → 更新 Q → 利用 → 再探索 → 再更新……
小挑戰
A → B → 🏆 ↘ 💀

如果 Agent 只允許「試過一次就永遠不再走那條」，會有什麼問題？

看答案

它可能找不到真正最好的路。

例如第一次走 B 拿到 +1，就認定「B 很好」；但其實往 C 最後能拿 +100。

所以 RL 有一對核心概念：

  • Exploration（探索）：「我再試試其他選擇，說不定有更好的。」
  • Exploitation（利用）：「我已經知道右邊不錯，那就一直走右邊。」

常見做法是 ε-greedy：有 ε 的機率亂試，否則走目前 Q 最大的動作。

Q 表：Agent 的「經驗表」

想像 Agent 有一張表，一開始什麼都不知道，所以都是 0：

StateActionQ-value
A往左0
A往右0
B往左0
B往右0
A —往右→ B —往右→ 🏆
     +1        +10

第一次它亂走，得到經驗：「從 B 往右，可以拿到 +10」。 於是開始更新 Q(B, 往右)。接著這個資訊又可以往前傳：

B 很有價值
↓
所以「A 往右到 B」也變得有價值
↓
🏆 +10 的資訊會一格一格往前傳

最後 Agent 不需要有人告訴它「A 要往右、B 要往右」—— 它可以從一次次經驗裡自己建立出這套策略。

🔥 小挑戰
Q(A, 左) = 3 Q(A, 右) = 8

Agent 現在在 A。如果完全不做 Exploration，只做純粹的 Exploitation， 它會選哪個？為什麼？

看答案

選右。因為 8 > 3。

這裡有個細節：Q-value 代表「從現在這個狀態採取這個 Action， 預期能的長期回報」，不是單純的立刻獲利。 所以純 exploitation：選目前估計長期價值較高的那個。

Exploration 則是：「雖然右邊看起來比較好，但偶爾還是試試左邊， 說不定左邊其實有更好的未來。」

這告訴我們 RL 不只在學什麼？

看答案

不只是「怎麼到終點？」而是 「怎麼用更好的方式到終點？」

Agent 每次走完都會更新：「在這個 State 做這個 Action，到底有多好？」

更新式：先聽故事，再看公式

假設某一次：
目前 Q(右) = 5
實際 Reward = +2
下一 State 的最佳 Q-value = 10
γ = 0.9
先不要管 α，暫時假設完全按照新的估計更新

新的估計目標 = 2 + 0.9 × 10 = 11
關鍵釐清

Q(A, 右) 是「A 往右的平均獲利」嗎？

看精確說法

不完全是。「平均獲利」的說法容易誤導。

Q(A, 右) 比較接近： 「如果我現在在 A，選擇『右』這個 Action， 那麼從這個選擇開始，我預期未來可以得到多少累積回報？」

所以它不是單純「往右平均拿多少錢」，而是往右這個決策的長期價值估計。

Q(s,a) ← Q(s,a) + α [ r + γ · maxa′ Q(s′,a′) − Q(s,a) ]
翻譯成人話： 新的 Q 值 = 舊的 Q 值 + 學習率 ×（這次實際看到的目標 − 舊的 Q 值）
  • 這次實際看到的目標 = r + γ ×（下一狀態的估計）
  • 「舊估計」→「實際拿到的 Reward」→「下一個 State 未來可能的 Value」→ 比較差異 → 修正 Q

SARSA vs Q-learning：差在「用誰的下一步」

SARSAQ-learning
更新時用的下一動作實際走的 A′Q 表裡最好的 a
類型同政策 on-policy離政策 off-policy
學到什麼「含探索的真實走法」好不好理論上最優怎麼走
懸崖上常見較安全的內側路較短但貼崖的路
經典懸崖結果。 Q-learning 的最優路線會貼著懸崖邊（最短）； SARSA 因為學習時真的會亂試掉崖，往往學出更靠內側的安全路線。 原因就藏在更新式：SARSA 把「探索造成的風險」也算進價值裡。

把整件事寫成可跑的 Python

表格型 Q-learning，環境用 Gymnasium 的 CliffWalking。就算沒裝，也能先讀懂邏輯。

import numpy as np

# ---- 最小 Q-learning（自製 1D 世界，不必裝任何東西）----
n_states, n_actions = 4, 2   # 0,1,2,3；動作 0=左 1=右
goal = 3
Q = np.zeros((n_states, n_actions))
alpha, gamma, epsilon = 0.5, 0.9, 0.2

def step(s, a):
    """Environment: 回傳 (next_state, reward, done)"""
    ns = s - 1 if a == 0 else s + 1
    ns = max(0, min(n_states - 1, ns))
    if ns == goal:
        return ns, +10.0, True
    return ns, -1.0, False

def choose(s):
    """ε-greedy：有 ε 亂試，否則走目前 Q 最大的動作"""
    if np.random.rand() < epsilon:
        return np.random.randint(n_actions)
    return int(np.argmax(Q[s]))

for episode in range(200):
    s = 0
    for t in range(20):
        a = choose(s)
        ns, r, done = step(s, a)

        # Q-learning 更新：下一格用 max Q（不管實際會走哪）
        best_next = Q[ns].max()
        td_target = r + gamma * best_next
        Q[s, a] += alpha * (td_target - Q[s, a])

        s = ns
        if done:
            break

print("Q 表：")
print(Q)
print("建議策略（每個狀態選 argmax）：", Q.argmax(axis=1))
更深一點 · 收斂條件（聽過就好）

教科書會說：在足夠探索（GLIE）、且步長滿足 Robbins–Monro （Σα=∞，Σα²<∞）時，表格型 Q-learning 會收斂到 Q*。 實作常用固定 α 與有限 ε——多半好用，但沒有形式保證。

「致命三合組」預告：bootstrapping（用自己估計當目標）+ 函數近似 + 離政策， 可能發散。第 4–5 週的目標網路與 replay，就是在對付這件事。

動手玩：懸崖世界

你可以這樣玩：

  1. 先跑 Q-learning 的「跑 50」幾次，看近 20 平均有沒有上升。
  2. 切到 SARSA 重置再跑，比較最後走的路線。
  3. 調大 ε：更愛亂試，早期可能更慘，但有機會發現更好的路。
  4. 調大 α：學得快但抖動；調小則慢而穩。
  5. 調小 γ：更只顧眼前。

理解題

哪一個是離政策（off-policy）方法？為什麼？

看答案

Q-learning，因為它更新時對下一格取 max Q(s′,a)，而不是「實際走的 A′」。

同政策 vs 離政策，取決於你 bootstrap 的是「誰的下一步」。
