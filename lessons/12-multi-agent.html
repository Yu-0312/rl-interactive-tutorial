Multi-agent Reinforcement Learning

Multiple learners interact. The environment is non-stationary from each agent’s viewpoint because others keep changing policies.

Central research axes

  • Cooperative / competitive / mixed incentives.
  • Centralized training, decentralized execution (CTDE).
  • Communication, credit assignment, opponent modeling.

MADDPG

Multi-Agent DDPG (Lowe et al.): each agent has an actor πi(oi) but may use a centralized critic Qi(x, a1…aN) that sees global state / joint actions during training.

∇θᵢ J = 𝔼[ ∇θᵢ πi(oi) ∇aᵢ Qi(x, a)|aᵢ=πᵢ(oᵢ) ]

At execution, only local observations + actor are needed.

MAML (meta-learning angle)

Model-Agnostic Meta-Learning finds initialization θ such that a few gradient steps adapt to a new task / new partners. In MARL: fast adaptation to new teammates or reward structures.

minθ Σtasks ℒτ( θ − α ∇θ ℒτ(θ) )

Cooperative vs competitive

CooperativeCompetitive
GoalMaximize team returnZero-sum / self-play
Credit assignmentCritical (who helped?)Often easier (win/lose)
MethodsQMIX, MAPPO, shared criticSelf-play, PSRO, league training
RiskCheap talk, lazy agentCycles, exploitability

Evaluation tips

  • Evaluate against unseen partners / seeds — not just training pool.
  • Report exploitability or cross-play matrices when relevant.
  • Ablate centralized info: does the critic actually need joint actions?
