多智能體強化學習

多個學習者互動。從每個智能體的角度看環境是非平穩的， 因為其他智能體的策略一直在變。

研究主軸

  • 合作 / 競爭 / 混合激勵。
  • 集中訓練、分散執行（CTDE）。
  • 溝通、信用分配、對手建模。

MADDPG

Multi-Agent DDPG（Lowe et al.）：每個智能體有演員 πi(oi)， 但訓練時可用集中式評論家 Qi(x, a1…aN) 看到全域狀態 / 聯合動作。

∇θᵢ J = 𝔼[ ∇θᵢ πi(oi) ∇aᵢ Qi(x, a)|aᵢ=πᵢ(oᵢ) ]

執行時只需局部觀測 + 演員。

MAML（元學習角度）

Model-Agnostic Meta-Learning 找初始化 θ，使少量梯度步就能適應新任務 / 新隊友。 在 MARL 中：快速適應新隊友或獎勵結構。

minθ Σtasks ℒτ( θ − α ∇θ ℒτ(θ) )

合作 vs 競爭

合作競爭
目標最大化隊伍回報零和 / 自我對弈
信用分配關鍵（誰有貢獻？）常較容易（輸贏）
方法QMIX、MAPPO、共享評論家Self-play、PSRO、聯賽訓練
風險廉價對話、懶惰智能體循環、可被利用

評估建議

  • 對未見過的隊友 / 種子評估——不只訓練池。
  • 相關時報告可利用性或交叉對弈矩陣。
  • 消融集中式資訊：評論家真的需要聯合動作嗎？
