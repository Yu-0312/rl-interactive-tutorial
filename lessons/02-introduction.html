一句話總結 Return 與折扣 手算小挑戰 Value 是什麼 往回流 Python 對照 GridWorld 演示 更深一點
第 2 週 · 互動 · 新手必修

在小地圖上算「哪裡比較好」（手算開始）

一句話總結。 Agent 的目標不是「單步拿最多」，而是長期累積獎勵（Return）最大。 未來的獎勵要打折扣 γ。把「從這裡出發大概能拿多少」寫成一個數字，就是 Value。

先從累積說起：Return（回報）

假設 Agent 學到一條路：

A → B → C → 🏆 +1 +1 +10

那麼從 A 開始的累積獎勵是：

1 + 1 + 10 = 12

所以即使 A → B 當下只有 +1，A 仍可能是「很有價值的狀態」—— 因為從這裡出發，未來可以接到 +10。

小挑戰

兩條路，如果你只看「最後總共拿多少」，會選哪條？
路線甲：A → B → 🏆，+1 +10，總共 11
路線乙：A → C → D → E → 🏆，+2 +2 +2 +10，總共 16

先想再看

只看總和，乙比較高。但這樣夠嗎？

若乙要走 1000 步才拿到 +10，甲只要 2 步就拿到 +10， 「16 一定比 11 好」就不成立了。 這就是為什麼 RL 需要 Discount Factor γ（折扣因子）： 未來的獎勵，我要打幾折？

手算：Value = 現在 + 打折後的未來

假設：在 A 往 B
當下 Reward = +2
B 的 Value V(B) = 10
γ = 0.9

那麼「A 往 B 這個選擇」的價值 ≈ 2 + 0.9 × 10 = 11
再進一步

A 有兩個選擇：
往 B：馬上 Reward = +2，且 V(B) = 10
往 C：馬上 Reward = +5，且 V(C) = 5
γ = 0.9
選 B 的價值？選 C 的價值？Agent 應該選哪個？

看答案
Q(A, B) = 2 + 0.9 × 10 = 11
Q(A, C) = 5 + 0.9 × 5 = 9.5

所以 Agent 在 A 應該選 B。

你剛剛算的東西，正式名字就是 Q-value： 「在這個 State 做這個 Action，預期未來大概值多少」。

  • V(s) →「我在這個狀態，這個狀態有多好？」
  • Q(s,a) →「我在這個狀態做這個動作，這個選擇有多好？」

注意：Q 不是「立刻賺多少」，而是包含未來回報的長期估計。 所以剛剛若你直覺「C 馬上 +5 比較好」，會被 0.9×10 的未來價值翻盤。

更深一點 · Bellman 的故事版

你剛剛其實已經碰到 Bellman Equation 的核心：

現在的價值 = 現在拿到的 Reward + 打折後的未來價值
Q(s,a) ≈ r + γ · V(s′)　　或　　Q(s,a) ≈ r + γ · maxa′ Q(s′,a′)

「估計會往回流」：終點旁邊先變有價值，再一格一格往回擴散。 這也是為什麼動態規劃（DP）能算出整張價值圖。

同一手算，用 Python 對照

# 手算 Q = r + gamma * V[next]
gamma = 0.9
V = {"B": 10.0, "C": 5.0}

options = {
    "A→B": {"r": 2.0, "next": "B"},
    "A→C": {"r": 5.0, "next": "C"},
}

Q = {}
for name, info in options.items():
    Q[name] = info["r"] + gamma * V[info["next"]]
    print(name, "→", Q[name])

best = max(Q, key=Q.get)
print("Agent 應該選:", best)   # 期望輸出 A→B = 11.0
程式 ↔ 手算一一對應。 Q[name] = r + gamma * V[next] 就是你剛剛在紙上寫的「2 + 0.9×10」。 之後價值迭代只是：把每一格都這樣刷新很多輪，直到數字穩定。

動手玩：價值如何「往回流」

你可以這樣玩：

  1. 演算法選「價值迭代」，按幾次單步，盯著顏色從目標 / 陷阱往旁邊擴散。
  2. 按連續執行，看箭頭（建議走法）如何穩定。
  3. 把 γ 調小：更只顧眼前，可能選超近但危險的路。
  4. 把 γ 調大：更願意繞遠避開陷阱。
  5. 切到「策略迭代」，比較兩種「算好壞」的節奏。

更深一點 · 價值迭代 vs 策略迭代

兩者都需要模型 P（知道做這動作會到哪）。價值迭代每次刷新： V(s) ← maxa Σ P [ R + γ V(s′) ]

策略迭代則是「評估目前策略 → 改進成更好的策略」交替，直到策略不再變。 白話：價值迭代一直在刷分數表；策略迭代在修規則本。 狀態空間巨大或模型未知時，兩者都用不了——那要等第 3 週無模型方法。

本週理解題

如果有人告訴你「State A 的 Value = 20」，你覺得這個 20 大概在描述什麼？ （不用術語，用自己的話）

看標準說法

接近「從 A 出發，之後大概還能累積拿多少」。 更精確一點： Value（價值）= 從某個 State 出發，按照某個策略行動後，預期能得到的未來累積回報。

  • Reward：這一步拿多少
  • Return：這一連串最後累積多少
  • Value：現在這個 State「未來大概值多少」
