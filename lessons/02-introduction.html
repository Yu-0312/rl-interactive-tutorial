Dynamic Programming: Policy & Value Iteration

With a known model $P(s'|s,a)$ and reward $R(s,a,s')$, we can compute optimal values by sweeping the state space. These algorithms are the foundation for every model-free method that follows.

MDP recap

  • State $s \in \mathcal{S}$ — what the agent observes (fully, in DP).
  • Action $a \in \mathcal{A}(s)$.
  • Transition $P(s' \mid s, a)$.
  • Reward $R(s,a,s')$.
  • Discount $\gamma \in [0,1)$.
G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + … = Σ_{k=0}^∞ γ^k R_{t+k+1}

Bellman equations

State-value under policy π:

vπ(s) = Σa π(a|s) Σs' P(s'|s,a) [ R(s,a,s') + γ vπ(s') ]

Optimal value (Bellman optimality):

v*(s) = maxa Σs' P(s'|s,a) [ R(s,a,s') + γ v*(s') ]

Policy Iteration

Alternates two steps until the policy is stable:

  1. Policy Evaluation: solve linear system / iterate $v_{k+1} = T^\pi v_k$ until convergence.
  2. Policy Improvement: $\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R + \gamma v(s')]$.
Guarantee. Policy Iteration converges to an optimal policy in finite time for finite MDPs (policy is improved strictly until stable).

Value Iteration

Compress evaluation into a single sweep using the optimality operator:

vk+1(s) ← maxa Σs' P(s'|s,a) [ R(s,a,s') + γ vk(s') ]

When $v$ stops changing (within ε), extract the greedy policy. Often fewer full iterations, each cheaper.

What you should notice

  • Values spread backward from the goal and pit — this is backup.
  • Higher γ makes far rewards matter more; the agent prefers longer safe paths.
  • Policy Iteration: each “Step” does full evaluation (multiple inner sweeps) then one improvement.
