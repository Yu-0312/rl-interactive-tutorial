動態規劃：策略迭代與價值迭代

在已知模型 $P(s'|s,a)$ 與獎勵 $R(s,a,s')$ 下，我們可以掃過整個狀態空間 算出最優價值。這是後續所有無模型方法的基礎。

MDP 複習

  • 狀態 $s \in \mathcal{S}$。
  • 動作 $a \in \mathcal{A}(s)$。
  • 轉移 $P(s' \mid s, a)$。
  • 獎勵 $R(s,a,s')$。
  • 折扣 $\gamma \in [0,1)$。
G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + … = Σ_{k=0}^∞ γ^k R_{t+k+1}

Bellman 方程

策略 π 下的狀態價值：

vπ(s) = Σa π(a|s) Σs' P(s'|s,a) [ R(s,a,s') + γ vπ(s') ]

最優價值（Bellman 最優性）：

v*(s) = maxa Σs' P(s'|s,a) [ R(s,a,s') + γ v*(s') ]

策略迭代

交替兩步直到策略穩定：

  1. 策略評估：解線性系統 / 迭代 $v_{k+1} = T^\pi v_k$ 至收斂。
  2. 策略改進：$\pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a)[R + \gamma v(s')]$。
保證。 有限 MDP 上策略迭代在有限步內收斂到最優策略（策略被嚴格改進直到穩定）。

價值迭代

把評估壓進一輪掃描，直接用最優算子：

vk+1(s) ← maxa Σs' P(s'|s,a) [ R(s,a,s') + γ vk(s') ]

當 $v$ 不再變化（在 ε 內），取出貪婪策略。迭代次數常更少，每步更便宜。

即時 GridWorld 演示

經典網格：起點、目標（+1）、陷阱（−1）與小步進成本。 觀察價值熱力圖如何填滿、貪婪箭頭如何穩定。

你應該觀察到

  • 價值從目標與陷阱反向擴散——這就是 backup。
  • γ 越大，遠端獎勵越重要；智能體更偏好較長的安全路徑。
  • 策略迭代：每次「單步」做完整評估（多個內部掃描）再做一次改進。
