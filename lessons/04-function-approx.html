狀態太多記不住？改用近似

一句話總結。 Q 表要「每個狀態存一格」。狀態一多就爆。 解法：改用一組可調參數算出價值——相近狀態共用參數，順便學會泛化。 這叫函數近似。
還沒讀 ML 補課？ 建議先花 30 分鐘： ML 1 → ML 2。 本週的「特徵加權」就是線性模型。

先感受一下「表格會怎樣爆」

先想一想
小迷宮：10×10 = 100 狀態 → 表沒問題 CartPole：位置與角度是連續數值 → 狀態無限 遊戲畫面：84×84 像素 → 表根本存不下

連續狀態為什麼讓表格方法失敗？還有另一個隱藏問題是什麼？

看答案
  1. 記憶體：狀態無限 / 太多，表開不起來。
  2. 沒有泛化：在 A 格學到的經驗，對很像的 A′ 完全沒幫助——每個狀態都要重新摔一次。

近似方法兩件事一起解：參數比較少，而且「像的狀態」會互相支援。

從「查表」改成「算」

表格：V[s] = 某一格的數字
近似：V̂(s) = f(狀態 s ; 參數 w)
學習 = 調整 w，讓 f 吐出來的數字愈來愈準
線性版：V̂(s) = φ(s)·w = 各特徵分數的加權和

和 ML 補課的 ŷ = w·x 是同一件事， 只是 x 換成狀態特徵 φ(s)，目標換成 RL 的 TD 目標。

特徵：把狀態變成幾個數字

  • 位置編碼：狀態在 x=3 → 某個特徵亮起來。
  • Tile coding：好幾層稍微錯開的格子蓋住狀態空間。
為什麼 tile coding 會泛化？ 兩個靠近的狀態，往往在某些層落在同一小格 → 共用同一個參數 → 調這格時，附近的狀態也一起被調整了。
小挑戰
φ(s) = [1, 0, 1] （兩個特徵亮） w = [0.5, 2.0, -0.2] γ 與 r 先不管

V̂(s) = φ·w 大約是多少？（加權和）

看答案
V̂ = 0.5×1 + 2.0×0 + (−0.2)×1 = 0.3

就是「亮起來的特徵 × 對應權重」加總。狀態長得像時，亮的特徵重疊 → 估計值也會接近。

更新：TD 誤差 × 特徵

δ = r + γ · V̂(s′) − V̂(s)
w ← w + α · δ · φ(s)
這一次看到的目標 r + γV̂(s′)
減掉目前估計 V̂(s)
= 差距 δ
→ 往目標方向挪 α·δ，
但只調「這次用到的特徵」對應的權重
「半梯度」是什麼？ 更新時把「下一狀態的估計」當成固定目標，不對它再往回傳梯度。 這是刻意的——較穩。DQN 的目標網路想法很類似。

Python：線性 TD(0)

import random

# 一維軌道：位置 0..9，目標在 9
# 特徵：每個位置一個 one-hot（可換成 tile coding）
n_pos = 10
w = [0.0] * n_pos
alpha, gamma = 0.2, 0.9

def V(s):
    return w[s]          # 線性：φ(s) 是 one-hot

def env_step(s, a):
    """a: -1 左 / +1 右；終點 +1，走路 -1"""
    ns = max(0, min(n_pos - 1, s + a))
    if ns == n_pos - 1:
        return ns, 1.0, True
    return ns, -1.0, False

for episode in range(300):
    s = random.randint(0, n_pos - 2)
    for _ in range(30):
        a = random.choice([-1, 1])   # 先隨機探索
        ns, r, done = env_step(s, a)

        td_target = r + gamma * V(ns)
        delta = td_target - V(s)
        # one-hot → 只更新 w[s]
        w[s] += alpha * delta

        s = ns
        if done:
            break

print("V 估計:", [round(v, 2) for v in w])
print("參數大小 ‖w‖ ≈", round(sum(x*x for x in w) ** 0.5, 3))
把 V(s) = w[s] 換成 sum(φ(s)[i] * w[i])， 就是一般線性近似；把 φ 換成神經網路，就是第 5 週。

動手玩：tile coding 價值學習

你可以這樣玩：

  1. 先按「訓練 200」，看步數與 ‖w‖ 有沒有變化。
  2. Tilings 1→8：層數多，價值曲線通常更平滑。
  3. α 調很大：曲線可能抖甚至爆。
  4. γ 調小：更只顧眼前。

更深一點 · 致命三合組

下列三件事同時發生時，學習可能發散：

  1. Bootstrapping：目標用到自己的估計。
  2. 函數近似：改一個參數，很多狀態一起變。
  3. 離政策：資料來自亂試，目標卻在算最優。
δ = r + γ max Q(s′,a′; w) − Q(s,a; w)　← 目標裡也有 w

第 5 週的 replay + 目標網路，就是在拆這組炸彈。

理解題

函數近似相對「表格」最大的好處？

看答案

用較少參數，在相似狀態之間共享、泛化。

不是「比較快收斂」，也沒有「不用探索」——那些都是誤解。
