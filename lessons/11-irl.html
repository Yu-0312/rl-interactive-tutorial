逆強化學習（Inverse RL）

正向 RL：獎勵 → 最優策略。IRL：示範或偏好 → 恢復一個能解釋該行為的獎勵，然後（可選）對其優化。

問題定義

給定專家軌跡 τE，找出 R 使專家在 R 下（近似）最優。

  • 獎勵只在塑形勢函數與常數意義下可辨識。
  • 許多獎勵可合理化同一策略——需要先驗 / 正則化。

經典演算法

  • MaxEnt IRL：在軟最優分佈下匹配特徵期望。
  • Apprenticeship learning：匹配特徵計數；與 RL oracle 對弈。
  • GAIL / AIRL：對抗式模仿——區分專家與智能體的狀態/動作。
模仿 vs IRL。 行為克隆（BC）做狀態→動作映射，會有誤差複合。 IRL/IL 方法用 on-policy rollout 修正分佈偏移（DAgger 家族）。

從人類偏好做深度 RL

不必給完整示範，給人類兩段軌跡片段問哪個更好。 用 Bradley–Terry 擬合偏好模型（在學到的 $\hat{R}_\psi$ 上）：

P(τ¹ ≻ τ²) = σ( Σ t̂ rψ(s,a)t¹ − Σ t̂ rψ(s,a)t² )

然後對 $\hat{R}_\psi$ 跑 RL。

RLHF 概覽（LLM）

  1. SFT：在高品質答案上監督微調。
  2. 獎勵模型：用人類/AI 成對偏好標籤訓練。
  3. RL（PPO / DPO 變體）：對 RM 優化策略，並對 SFT 參考加 KL。

陷阱

  • 獎勵駭入：智能體利用 RM 錯誤（Goodhart）。
  • 偏好雜訊：標註者不一致；需要集成 / 不確定性。
  • 分佈偏移：RM 只在見過的策略區域訓練。
  • 過度優化：KL 與 early stopping 很重要。
