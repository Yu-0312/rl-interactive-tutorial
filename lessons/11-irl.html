Inverse Reinforcement Learning

Forward RL: reward → optimal policy. IRL: demonstrations or preferences → recover a reward that explains the behavior, then (optionally) optimize it.

Problem statement

Given expert trajectories τE, find R such that expert is (near-)optimal under R.

  • Reward is only identifiable up to shaping potentials and constants.
  • Many rewards rationalize the same policy — need priors / regularization.

Classic algorithms

  • MaxEnt IRL: match feature expectations under a soft-optimal distribution.
  • Apprenticeship learning: match feature counts; game with RL oracle.
  • GAIL / AIRL: adversarial imitation — discriminate expert vs agent states/actions.
Imitation vs IRL. Behavioral cloning maps states → actions and suffers compounding error. IRL/IL methods use on-policy rollouts to correct distribution shift (DAgger family).

Deep RL from human preferences

Instead of full demonstrations, show a human two trajectory clips and ask which is better. Fit a preference model (e.g. Bradley–Terry on a learned reward $\hat{R}_\psi$):

P(τ¹ ≻ τ²) = σ( Σ t̂ rψ(s,a)t¹ − Σ t̂ rψ(s,a)t² )

Then run RL against $\hat{R}_\psi$.

RLHF at a glance (LLMs)

  1. SFT: supervised fine-tune on high-quality answers.
  2. Reward model: train on pairwise human/AI preference labels.
  3. RL (PPO / DPO variants): optimize policy against RM with KL to SFT reference.

Pitfalls

  • Reward hacking: agent exploits RM errors (Goodhart).
  • Preference noise: labelers disagree; need ensembles / uncertainty.
  • Distribution shift: RM only trained on seen policy regions.
  • Sycophancy / over-optimization: KL and early stopping matter.
