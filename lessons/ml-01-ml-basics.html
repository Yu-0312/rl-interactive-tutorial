機器學習是什麼？（給完全沒學過的人）

一句話總結。 機器學習（ML）不是「讓電腦變聰明」的魔法， 而是：給很多例子，讓電腦自動調參數，好讓「輸出」盡量接近「我們想要的答案」。 強化學習會用到 ML 的工具（尤其是神經網路），但先懂這句就夠入門。

為什麼這份 RL 教材要補 ML？

第 1–3 週的表格型 RL 不需要 ML。 但第 4–5 週起，狀態多到開不了表，我們會改用「可調參數的公式 / 神經網路」去估價值。 那時你會遇到：特徵、損失、梯度下降、網路。

建議插入時機。 學完第 3 週（Q 表會動了）之後、進入第 4 週之前，把本系列三課讀完即可。 也可以先跳過，卡住再回來。

先看最經典的一種：監督式學習

想像你要教電腦「看圖片認貓」：

輸入（圖片） → 模型 → 輸出（是貓 / 不是貓）
↑ 有標準答案！每張圖都標好了標籤

流程很像學生做題對答案：

  1. 模型看一張圖，猜一個答案。
  2. 和標準答案比，算出猜錯多少（這就是損失 loss）。
  3. 調整模型內部的參數，讓下次猜得更準。
  4. 重複幾千、幾百萬次。
先想一想 · 點選答案

下面哪一個比較像監督式學習？

完整說明
監督式學習強化學習
學習信號標準答案（標籤）獎勵 / 懲罰
資料別人整理好的一筆筆自己邊做邊收集
像什麼看答案本刷題學騎腳踏車

五個關鍵詞（之後每週都會用）

名詞白話例子
特徵 x描述「這題長什麼樣」的數字身高 170、體重 60、年齡 25
標籤 y標準答案「有病」=1、「沒病」=0
模型看到 x，吐出預測 ŷ 的規則一條直線：ŷ = w·x + b
參數模型裡可以調的旋鈕斜率 w、截距 b
損失 Loss猜錯多少（越小越好）(ŷ − y)²
目標：調整參數，讓損失變小
→ 預測就愈來愈接近標準答案
小挑戰 · 點選答案
x = 2, ŷ = w·x, w = 3, y = 10

ŷ、loss 分別是多少？w 要調大還是調小？

完整說明
ŷ = 3 × 2 = 6
loss = (6 − 10)² = 16

至於「要調多少」——下一課的梯度下降就是在回答這件事。

同一概念，用 Python 寫

只用標準函式庫。你不需要 TensorFlow / PyTorch 就能懂這件事。

# 線性模型：y_hat = w * x
# 目標：找一個 w，讓預測接近答案

x = 2.0
y = 10.0
w = 3.0
lr = 0.1          # 學習率：每一步調多少

for step in range(20):
    y_hat = w * x
    loss = (y_hat - y) ** 2

    # 「如果 w 變大一點，loss 會變大還是變小？」
    # 對這個模型：dL/dw = 2 * (y_hat - y) * x
    grad = 2 * (y_hat - y) * x
    w = w - lr * grad       # 往 loss 變小的方向走一小步

    if step % 5 == 0 or step == 19:
        print(f"step={step:02d}  w={w:.3f}  y_hat={y_hat:.3f}  loss={loss:.3f}")

print("最後 w ≈", round(w, 3), "（理論上應接近 5，因為 5×2=10）")
你剛剛已經做了「機器學習的核心循環」： 預測 → 算 loss → 用梯度修正參數 → 重複。 神經網路只是把「ŷ = w·x」換成很多層的可調公式；精神完全一樣。

和 RL 怎麼接起來？

到了第 4–5 週，表格換成模型時，對應關係是：

監督式學習RL 裡對應成
輸入 x狀態 s（或狀態+動作）
標籤 y「目標 Q / 目標 V」（會動，不是人標的）
模型 ŷQ(s,a; θ) 或 V(s; θ)
參數網路權重 θ
loss(Q 現在估的 − 學習目標)²
一個關鍵差異（記起來）。 監督式學習的 y 是固定的標準答案； RL 的「學習目標」會隨模型自己改變——這就是為什麼 RL 較容易不穩， 也是 DQN 要「目標網路」的原因（第 5 週）。
更深一點 · ML 的三大類（聽過就好）
  • 監督式：有標籤（分類 / 回歸）。
  • 非監督式：沒標籤，找結構（分群、降維）。
  • 強化學習：靠互動與獎勵，學決策。

RLHF（聊天模型）則是「用 RL 優化一個從人類偏好訓練出來的獎勵模型」——第 11 週會講。
