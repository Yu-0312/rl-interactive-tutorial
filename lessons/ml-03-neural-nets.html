神經網路直覺：很多可調旋鈕串在一起

一句話總結。 神經網路 = 很多層「加權和 + 一點非線性」串起來的可調函數。 它的輸出可以是「是貓的機率」，也可以是「這個狀態-動作的 Q 值」。 訓練方式仍然是：算 loss → 反向傳播拿梯度 → 更新權重。

為什麼表格不夠，要網路？

  • 格子世界 48 格：開表 OK。
  • 遊戲畫面 84×84 灰階像素：狀態數 ≈ 天文數字，表開不起來。
  • 而且相似的畫面（只差 1 個像素）應該有相似的價值——表沒有這種「泛化」。
網路做的事： 輸入狀態 → 算出 Q 值（或動作），而不是去表裡查。 相近的輸入，因為共用同一組權重，自然有相近的輸出。

前向傳播：資料怎麼流過去

輸入 x（狀態特徵 / 像素）
↓　每一層：先做加權和 z = W·h + b
↓　再過非線性：h = ReLU(z)　（把負值變 0，引入彎曲能力）
↓　重複幾層
輸出 ŷ（例如：每一個動作的 Q 值）
一層的白話：輸出 = 活化函數( 權重 × 上一層輸出 + 偏置 )
先想一想

如果只有「加權和」沒有非線性（ReLU 等），疊 100 層網路，本質上等於什麼？

看答案

等於還是一條直線（線性函數）——線性接線性仍是線性。

所以非線性活化函數不能省：它讓網路有資格擬合彎彎曲曲的複雜關係， 例如「像素 → 玩遊戲的分數」。

完整訓練循環（和 ML 補課 2 同一套）

  1. 拿一批資料（RL 裡常從「經驗回放袋」抽）。
  2. 前向：算出預測 ŷ / Q(s,a)。
  3. 對目標算 loss。
  4. 反向傳播：算出每個權重的梯度。
  5. θ ← θ − α·∇L。
  6. 重複很多很多次。

用純 Python 摸一次「可調函數」

下面不是完整深度學習框架，而是單層網路 + 梯度下降的最小可跑版本， 幫你把「網路參數被 loss 推著走」這件事看清楚。 

import math

# 資料：想學 y ≈ 2*x1 - 3*x2 + 1
data = [
    ([1.0, 0.0], 3.0),
    ([0.0, 1.0], -2.0),
    ([1.0, 1.0], 0.0),
    ([2.0, 1.0], 2.0),
]

w = [0.0, 0.0]   # 權重
b = 0.0          # 偏置
lr = 0.05

def predict(x):
    return w[0]*x[0] + w[1]*x[1] + b

def relu(z):
    return z if z > 0 else 0.0

# （可選）加一個 ReLU 隱藏層：h = relu(v·x), ŷ = w·h + b
# 為了看得清楚，主循環先用線性版

for epoch in range(200):
    total_loss = 0.0
    gw = [0.0, 0.0]
    gb = 0.0
    for x, y in data:
        y_hat = predict(x)
        err = y_hat - y
        total_loss += err * err
        # MSE 梯度
        gw[0] += 2 * err * x[0]
        gw[1] += 2 * err * x[1]
        gb += 2 * err
    n = len(data)
    w[0] -= lr * gw[0] / n
    w[1] -= lr * gw[1] / n
    b -= lr * gb / n
    if epoch % 40 == 0 or epoch == 199:
        print(f"epoch={epoch:3d}  loss={total_loss/n:.4f}  w={w}  b={b:.3f}")

print("學到的權重接近 [2, -3]，偏置接近 1 嗎？")
for x, y in data:
    print("x=", x, "pred=", round(predict(x), 3), "true=", y)
把 w 換成很多層矩陣，你就得到「真」神經網路。 框架（PyTorch）只是幫你自動算梯度（autograd）與 GPU 加速； 觀念不變：loss 驅動權重更新。
更深一點 · 用 PyTorch 長什麼樣（第 5 週會用）
import torch
import torch.nn as nn

class QNet(nn.Module):
    def __init__(self, n_obs, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_obs, 64),
            nn.ReLU(),
            nn.Linear(64, n_actions),
        )
    def forward(self, x):
        return self.net(x)

model = QNet(n_obs=4, n_actions=2)   # 例如 CartPole
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

# 訓練一步的概念版
states = torch.randn(32, 4)
actions = torch.randint(0, 2, (32,))
targets = torch.randn(32)

q = model(states).gather(1, actions.unsqueeze(1)).squeeze(1)
loss = nn.functional.mse_loss(q, targets)
opt.zero_grad()
loss.backward()   # 反向傳播
opt.step()        # 梯度下降

安裝：pip install torch。 第 5 週的 DQN 就是「這個網路 + 回放袋 + 目標網路」。

接到 RL：DQN 的角色分配

零件它在 DQN 裡做什麼
Q 網路看到狀態，輸出每個動作的 Q 值
目標網路另一份較舊的權重，專門算「學習目標」，避免追自己尾巴
回放袋存舊經驗，訓練時隨機抽，打散資料黏性
loss(Q 目前 − 目標 y)²
優化器Adam / SGD，做 θ ← θ − α∇L
