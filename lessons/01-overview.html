第 1 週

課程總覽與環境設定

本互動教材對應完整一學期強化學習課程。第 1 週先建立心智模型、軟體環境， 以及後面幾週能順利動手的習慣。

學習目標

  • 說明智能體–環境迴圈，以及 RL 與監督式學習的差異。
  • 定義 MDP：$(S, A, P, R, \gamma)$ 與回報 $G_t$。
  • 建好 Python RL 環境（Gymnasium + NumPy，可選 PyTorch）。
  • 掌握課程弧線：精確 DP → 無模型 TD → 函數近似 → 深度 RL → 策略搜尋 → 進階主題。
學習建議。 每週共用一個筆記本（或 repo）：演算法名稱、更新式、 一句直覺、可執行腳本連結。之後就是專題的參考工具箱。

環境設定

建議技術堆疊（Python 3.10+）：

# 先建立 venv / conda env，然後：
pip install gymnasium numpy matplotlib
pip install torch          # 深度 RL 週（5、7、10）
pip install jupyterlab     # 可選

# 冒煙測試
python -c "import gymnasium as gym; print(gym.make('CliffWalking-v0'))"
元件用途備註
Gymnasium標準環境 API建議 CliffWalking、FrozenLake、CartPole
NumPy表格型演算法第 2–4 週足夠
PyTorchDQN / PPO / SACGPU 可選；小網路用 CPU 即可
Matplotlib學習曲線務必畫多 seed 的 mean ± std

課程地圖

精確與表格型

第 2–3 週：可證明收斂。小狀態空間。建立 bootstrapping 與探索直覺的最佳起點。

近似與深度 RL

第 4–5 週：用線性 FA 與神經網路泛化。replay、目標網路與穩定性成為主要工程議題。

策略優化

第 6–7、10 週：黑盒搜尋、REINFORCE、PPO 與 Actor-Critic。連續控制的主流方法。

前沿與專題

第 11–14 週：偏好、多智能體、模型式效率、實驗設計。之後進入學期專題。

程式庫 / 工具習慣

  • 一個演算法一個檔案：q_learning.py、ppo.py…
  • 設定即資料：α、ε、γ、網路大小放 dict 或 argparse——不要寫死在迴圈裡。
  • 隨機種子：暴露 seed 並記錄。沒有 seed 的 RL 結果只是軼事。
  • 檢查點：存最佳評估回報，而不是最後一組權重。

第一週清單

  1. 安裝 Gymnasium，隨機跑 FrozenLake-v1 10 個 episode。
  2. 寫出回報公式 $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$，用一句話解釋 γ。
  3. 瀏覽第 2–3 週互動演示——把價值迭代跑到策略不再變化。
  4. 寫 5 行專題想法（可選，第 8–9 週再細化）。
