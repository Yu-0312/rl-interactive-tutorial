第 1 週 · 新手必修 · 對話式

強化學習是什麼？（要先會機器學習嗎？）

一句話總結。 RL 是：一個「會做決定的東西」在環境裡試誤， 用獎勵慢慢學會「怎麼做比較好」。 表格型基礎（第 1–4 週）不需要先修機器學習； 到神經網路方法（第 5 週起）才會用到 ML 概念。

先回答：機器學習會不會是前置作業？

簡短答案：不是硬性前置，但強烈建議並行補上。 這份教材的設計是「先建立 RL 直覺，再補深度工具」。

不需要先會

第 1–3 週：狀態、獎勵、Q 表、手算更新。只要會加減乘除與「看懂一點 Python」即可。

會一點更好

向量與矩陣直覺：第 4 週函數近似會把特徵加權起來（像線性模型）。

之後才需要

第 5 週起（DQN / PPO）：神經網路、梯度下降、損失函數——這時「機器學習」才變成真前置。

並行建議

若你完全沒碰過 ML：先學完本教材第 1–3 週，同時用 1–2 週補「什麼是模型、什麼是梯度」即可銜接。

一句話對照。 監督式學習：給標準答案，抄著學。 強化學習：沒有每一步的答案，只有「這次結果好不好」，自己試出來。 所以 RL 的入門門檻在「思維」，不在「會不會用 TensorFlow」。

先不要背公式。我問你四個問題

假設機器人現在站在地圖中央，可以選擇「左」或「右」。 你就算完全不知道術語也沒關係，直接用自己的話回答：

先想一想 · 點選答案

下面四個東西，哪一組「你的說法 ↔ RL 術語」對應最完整？

原題：①機器人本身 ②「站在地圖中央」 ③「左/右」 ④「終點+10/陷阱−10」
完整說明
你的說法RL 正式概念例子
訓練目標 / 機器人Agent（智能體）機器人本身
定位 / 現在在哪State（狀態）站在地圖中央
方向 / 可以做什麼Action（動作）往左、往右
獎勵機制 / 加減分Reward（獎勵）終點 +10、陷阱 −10

有一點要修正：「訓練目標」≠ Agent。 Agent 是誰在學習、誰在做決定； 真正的目標是：最大化長期累積獎勵。

一次完整的 RL 互動長怎樣

Agent → 選一個 Action → Environment 回饋
→ 得到 Reward + 下一個 State → Agent 再決定下一步
小挑戰 · 點選答案

機器人在 A，選「上」撞牆：沒移動，Reward = −1。
哪一組 State / Action / Next State / Reward 是對的？

完整說明

這就是一次完整的 RL interaction： State → Action → Environment → Reward + Next State。

「撞牆有沒有回饋？」——有，而且很重要。 Reward 怎麼設計，會直接影響 Agent 最後學到什麼行為。 撞牆可以是 0、−1 或 −5；三種設定，學到的路線可能都不一樣。

把核心概念串成一條線

Agent
↓ 誰在做決定
State → Action → Reward
↓ 這一連串累積起來
Return（回報：整段路徑的累積獎勵）
↓ 未來要打折扣 γ
Value / Q-value（估計未來大概能拿多少）
↓ 根據估計決定怎麼走
Policy（策略）
↓ 一邊試新的、一邊用舊的
Exploration ↔ Exploitation

這條線就是後面每一週的骨架。第 2 週會把 Value 算給你看； 第 3 週會把 Q 表一格一格更新出來。

同一件事，用程式寫一次

不需要先會 ML。你只要能看懂「字典像表格、函數像步驟」就夠了。

# 最小 RL 迴圈：Agent 在 1D 世界，只能往右走
# 狀態: 0, 1, 2（2 是終點）
# 動作: "right"
# 終點 reward = +10，走路 reward = -1

state = 0
total_reward = 0
gamma = 0.9          # 未來打幾折，第 2 週會細講
V = {0: 0.0, 1: 0.0, 2: 0.0}   # 每個狀態「大概有多好」的估計

for step in range(5):
    action = "right"                 # 先固定往右（之後才學「怎麼選」）
    next_state = state + 1
    reward = 10.0 if next_state == 2 else -1.0
    total_reward += reward

    print(f"State={state}  Action={action}  "
          f"Reward={reward}  Next={next_state}")

    # 用「剛剛看到的結果」回頭修一點估計（TD 的雛形）
    td_target = reward + gamma * V[next_state]
    V[state] += 0.3 * (td_target - V[state])   # 0.3 是學習率 α

    state = next_state
    if state == 2:
        break

print("累積 Reward =", total_reward)
print("Value 估計 =", V)
print("這個 value 0.3 這個學習率 α")
你剛剛在程式裡已經碰到三件事： ① 互動迴圈（State→Action→Reward→Next State）； ② 累積回報（total_reward）； ③ 用經驗修正估計（那行 V[state] += ...）。 後面所有花式方法，都是在把③做得更穩、更快、更通用。

更深一點（可第二遍再看）

更深一點 · 術語正式版

RL 的形式骨架是 MDP（馬可夫決策過程）： 狀態集合 S、動作集合 A、轉移 P(s′|s,a)、獎勵 R(s,a,s′)、折扣 γ。

Gt = Rt+1 + γ Rt+2 + γ² Rt+3 + …

Agent 的目標是最大化期望的 G。若環境模型 P 已知，屬於「有模型」方法（第 2 週 DP）； 若未知，只能靠採樣經驗，屬於「無模型」方法（第 3 週以後）。

更深一點 · 為什麼 RL 不一定要先會 ML

表格型方法只需要「陣列 + 迴圈 + 期望估計」。 機器學習（尤其是深度學習）是在狀態空間太大、無法開表時， 用參數化函數去近似價值或策略——那是工具，不是 RL 的定義。 你可以先懂「在試什麼」，再換更強的估計器。
