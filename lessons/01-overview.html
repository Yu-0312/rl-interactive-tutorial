Week 1

Course Overview & Environment Settings

This interactive tutorial mirrors a full-semester Reinforcement Learning course. Week 1 is about setting the mental model, the software stack, and the habits that make later weeks productive.

Learning goals

  • Explain the agent–environment loop and why RL differs from supervised learning.
  • Define an MDP: $(S, A, P, R, \gamma)$ and the return $G_t$.
  • Set up a working Python RL environment (Gymnasium + NumPy, optional PyTorch).
  • Know the course arc: exact DP → model-free TD → function approximation → deep RL → policy search → advanced topics.
Study tip. Keep a single notebook (or repo) for every week: algorithm name, update equation, one-sentence intuition, and a link to your runnable script. That becomes your term-project reference kit.

Course roadmap

Exact & tabular

Weeks 2–3: you can prove things converge. Small state spaces. Best place to build intuition about bootstrapping and exploration.

Approximation & deep RL

Weeks 4–5: generalize across states with linear FA and neural nets. Replay, targets, and stability become the main engineering concerns.

Policy optimization

Weeks 6–7, 10: black-box search, REINFORCE, PPO, and actor-critic. Dominant methods for continuous control.

Frontiers & projects

Weeks 11–14: preferences, multi-agent, model-based efficiency, experiment design. Then your term project takes center stage.

Repo / tooling conventions

  • One algorithm per file: q_learning.py, ppo.py, …
  • Config as data: put α, ε, γ, network sizes in a dict or argparse — never hard-code in the loop.
  • Seeds: expose seed and log it. RL results without seeds are anecdotes.
  • Checkpoints: save best eval return, not just last weights.

First-week checklist

  1. Install Gymnasium and run FrozenLake-v1 for 10 random episodes.
  2. Write the return formula $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$ and explain γ in one sentence.
  3. Skim the interactive demos in Weeks 2–3 — run Value Iteration until the policy stops changing.
  4. Write a 5-line project idea (optional this early; refine in Weeks 8–9).
