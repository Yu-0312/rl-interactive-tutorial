損失與梯度下降：參數怎麼「被調」？

一句話總結。 Loss 告訴你現在猜得多糟； 梯度 告訴你「每個參數往哪邊動一點，loss 會變小」； 梯度下降 就是沿著那個方向，小步小步一直走。

Loss 在量什麼？

預測 ŷ vs 標準答案 y
常見：MSE = (ŷ − y)²   ｜   MAE = |ŷ − y|

白話：把「錯多遠」變成一個數字。 訓練的全部目的，就是讓這個數字變小。

先想一想
y = 10 模型 A 預測 9 → |error| = 1 模型 B 預測 2 → |error| = 8

哪一個模型目前比較好？如果用 (ŷ−y)²，它們的 loss 分別約是多少？

看答案

A 比較好。

A loss ≈ (9−10)² = 1
B loss ≈ (2−10)² = 64

用平方會放大大錯——B 的 loss 是 A 的 64 倍，訓練時會被狠狠修正。

梯度：「往哪邊調一點比較好」

不必怕這個詞。你可以把參數想成山上的位置，loss 是海拔高度：

梯度 ≈ 「往哪個方向，山會變高」
梯度下降 ≈ 往反方向下山（讓 loss 變小）
參數 ← 參數 − 學習率 × 梯度
θ ← θ − α · ∇L(θ)

白話：往「讓 loss 變小」的方向，挪一小步。 α（學習率）就是這一步有多大。

算給你看：一個參數的梯度下降

模型：ŷ = w · x x = 2, y = 10, w = 3 loss = (w·x − y)²
ŷ = 3×2 = 6
error = 6 − 10 = −4
∂loss/∂w = 2 × error × x = 2 × (−4) × 2 = −16
若 α = 0.05：w ← 3 − 0.05×(−16) = 3 + 0.8 = 3.8

梯度是負的，所以減掉負梯度 = w 變大。 這和上一課「預測太小要調大 w」一致。

自己寫一次，並觀察 loss

x, y = 2.0, 10.0
w = 3.0
lr = 0.05
history = []

for step in range(30):
    y_hat = w * x
    loss = (y_hat - y) ** 2
    grad = 2 * (y_hat - y) * x
    w = w - lr * grad
    history.append((step, w, y_hat, loss))

for step, w, y_hat, loss in history[::5]:
    print(f"step={step:02d}  w={w:.3f}  y_hat={y_hat:.3f}  loss={loss:.4f}")

print("收斂 w →", round(w, 3))   # 應接近 5.0
更深一點 · 多個參數與向量

真實模型有很多參數 θ = (w₁, w₂, …, wₙ)。 梯度 ∇L 也是一個向量：每個分量表示「對應參數稍微變大時，loss 變多快」。 更新仍然是同一條式子：θ ← θ − α ∇L。

ŷ = w₁x₁ + w₂x₂ + … + b

神經網路只是把很多這樣的線性式用「非線性函數」串起來， 再用反向傳播（backprop）有效率地算出每個權重的梯度。 你不需要一開始就手推 backprop；只要知道：它就是「算梯度的演算法」。

學習率 α：太大太小都會出事

α 太小剛好α 太大
學超慢，像在爬 穩定往下走 一步跨過谷底，loss 飛起來甚至爆炸 
# 把 lr 改成 1.5 跑一次上一段程式，觀察 loss
# 再改 0.0001 感受「太慢」
lr = 1.5      # 危險：可能震盪 / 爆炸
# lr = 0.0001  # 太保守
小挑戰
w = 3, grad = −16, lr = 0.1

新的 w 是多少？這個更新是讓 loss 變大還是變小？

看答案
w ← 3 − 0.1 × (−16) = 3 + 1.6 = 4.6

往「預測變大、更接近 10」的方向走，loss 會變小。

若有人寫成 w ← w + α·grad（亂改正負號），就會愈學愈爛——符號很重要。

接回 RL：DQN 的 loss 長什麼樣

目標 y_target = r + γ · max Q(s′, a′; 目標網路)
目前網路輸出 Q(s, a; θ)
Loss = ( Q(s,a;θ) − y_target )²
→ 對 θ 做梯度下降

看出來了嗎？和監督式學習同一套「loss + 梯度下降」， 只是標籤 y 換成了「會變動的 RL 目標」。 這就是為什麼第 5 週之前一定要懂梯度。

和第 3 週 Q 表更新的對照。 Q 表：Q[s,a] ← Q[s,a] + α（目標 − Q[s,a]）　　（表格，直接改一格）
網路：θ ← θ − α ∇(Q(s,a;θ) − 目標)²　　　（參數，經由梯度間接改）
